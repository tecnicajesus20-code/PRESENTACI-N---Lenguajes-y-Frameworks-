Lenguajes Seleccionados

1. Python

RedMonk: #2 TIOBE: #1
  • Año / Creador: 1991 — Guido van Rossum.
  • Paradigma: Multiparadigma (imperativo, OO, funcional).
  • Tipeado: Dinámico (fuerte en la práctica).
  • Tipo: Alto nivel, interpretado / máquina virtual.
  • Uso Principal: IA, ciencia de datos, automatización, backend.
Hola Mundo: print("Hello, world!")
Para el estudiante: Excelente puerta de entrada. Permite empezar con sintaxis sencilla y escalar a IA o datos.

2. C

RedMonk: #10 TIOBE: #2
  • Año / Creador: ~1972 — Dennis Ritchie (Bell Labs).
  • Paradigma: Imperativo y estructurado/procedural.
  • Tipeado: Estático.
  • Tipo: Compilado, de bajo nivel / cercano al hardware.
  • Uso Principal: Sistemas operativos, firmware, sistemas embebidos.
Hola Mundo: #include <stdio.h> int main() { printf("Hello, world!\n"); return 0; }

3. C++

RedMonk: #7 TIOBE: #3
  • Año / Creador: 1985 — Bjarne Stroustrup.
  • Paradigma: Multiparadigma (procedural, OO, genérico).
  • Tipeado: Estático.
  • Tipo: Compilado, alto rendimiento.
  • Uso Principal: Motores de videojuegos, sistemas, finanzas.
Hola Mundo: #include <iostream> int main() { std::cout << "Hello, world!\n"; }

4. Java

RedMonk: #3 TIOBE: #4
  • Año / Creador: 1995 — James Gosling (Sun Microsystems).
  • Paradigma: Orientado a objetos.
  • Tipeado: Estático.
  • Tipo: Compilado a bytecode (JVM), multiplataforma.
  • Uso Principal: Backend empresarial, Android, sistemas distribuidos.
Hola Mundo: public class Main { public static void main(String[] args) { System.out.println("Hello, world!"); } }

5. C#

RedMonk: #4 TIOBE: #5
  • Año / Creador: 2000 — Anders Hejlsberg (Microsoft).
  • Paradigma: Multiparadigma, OO fuerte.
  • Tipeado: Estático.
  • Tipo: Compilado a IL/.NET.
  • Uso Principal: Ecosistema .NET, videojuegos (Unity), empresarial.
Hola Mundo: using System; class Program { static void Main() { Console.WriteLine("Hello, world!"); } }

6. PHP

RedMonk: #4 TIOBE: #13
  • Año / Creador: 1994/1995 — Rasmus Lerdorf.
  • Paradigma: Multiparadigma.
  • Tipeado: Dinámico.
  • Tipo: Interpretado, enfocado en web server-side.
  • Uso Principal: Desarrollo web, CMS (WordPress).
Hola Mundo: <?php echo "Hello, world!"; ?>

7. Go

RedMonk: #12 TIOBE: #14
  • Año / Creador: 2009 — Robert Griesemer, Rob Pike, Ken Thompson (Google).
  • Paradigma: Procedural con concurrencia nativa.
  • Tipeado: Estático.
  • Tipo: Compilado de alto rendimiento.
  • Uso Principal: Cloud, microservicios, infraestructura.
Hola Mundo: package main import "fmt" func main() { fmt.Println("Hello, world!") }

8. Rust

RedMonk: #20 TIOBE: #10
  • Año / Creador: 2010 — Graydon Hoare (Mozilla).
  • Paradigma: Multiparadigma (seguridad de memoria).
  • Tipeado: Estático y fuerte.
  • Tipo: Compilado de sistemas.
  • Uso Principal: Sistemas seguros, infraestructura, WebAssembly.
Hola Mundo: fn main() { println!("Hello, world!"); }

9. TypeScript

RedMonk: #6 TIOBE: Out 20
  • Año / Creador: 2012 — Anders Hejlsberg (Microsoft).
  • Paradigma: Multiparadigma.
  • Tipeado: Estático (Superset de JS).
  • Tipo: Transpilado a JavaScript.
  • Uso Principal: Frontend/Backend web escalable.
Hola Mundo: console.log("Hello, world!");

10. R

RedMonk: #13 TIOBE: #9
  • Año / Creador: 1993 — Ross Ihaka, Robert Gentleman.
  • Paradigma: Funcional / Vectorizado.
  • Tipeado: Dinámico.
  • Tipo: Interpretado especializado.
  • Uso Principal: Estadística, análisis de datos y gráficos.
Hola Mundo: cat("Hello, world!\n")

11. Ruby

RedMonk: #9 TIOBE: #16
  • Año / Creador: 1995 — Yukihiro "Matz" Matsumoto.
  • Paradigma: Orientado a Objetos puro.
  • Tipeado: Dinámico.
  • Tipo: Interpretado.
  • Uso Principal: Desarrollo web dinámico (Rails).
Hola Mundo: puts "Hello, world!"

12. Swift

RedMonk: #11 TIOBE: #17
  • Año / Creador: 2014 — Apple (Chris Lattner).
  • Paradigma: Multiparadigma / Orientado a protocolos.
  • Tipeado: Estático.
  • Tipo: Compilado.
  • Uso Principal: Aplicaciones ecosistema Apple (iOS, macOS).
Hola Mundo: print("Hello, world!")

13. Kotlin

RedMonk: #14 TIOBE: Out 20
  • Año / Creador: 2011 — JetBrains (Andrey Breslav).
  • Paradigma: OO y Funcional.
  • Tipeado: Estático.
  • Tipo: Compilado a JVM / Android.
  • Uso Principal: Desarrollo Android moderno, backend.
Hola Mundo: fun main() { println("Hello, world!") }
